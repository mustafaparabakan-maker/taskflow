# Postman Test Ekran Görüntüleri

Postman'de her isteği çalıştırdıktan sonra ekran görüntüsünü bu klasöre şu isimlerle kaydedin:

| Dosya | Test |
|-------|------|
| `01-gorev-ekleme.png`     | POST /tasks → 201 |
| `02-gorev-listeleme.png`  | GET /tasks → 200 |
| `03-gorev-detay.png`      | GET /tasks/:id → 200 |
| `04-gorev-guncelleme.png` | PUT /tasks/:id → 200 |
| `05-gorev-silme.png`      | DELETE /tasks/:id → 200 |

Ekran görüntüsünde istek URL'si, method, gövde (body) ve yanıt ile durum kodu görünmelidir.
